# Где взять мод Money Cheat

Файл мода лежит здесь: **BTD6_MoneyMod/MoneyCheat.zip** (1.4 КБ).

Скачать можно двумя способами:

## Способ 1 — скачать сам архив (нужен Python, без установки)
В папке проекта выполни:
```
python -m http.server 8000
```
Открой в браузере http://localhost:8000/BTD6_MoneyMod/MoneyCheat.zip и скачай.

## Способ 2 — скопировать файл руками
Просто перетащи/скопируй `MoneyCheat.zip` из этой папки на рабочий стол.

## Что с ним делать
Мод работает ТОЛЬКО через загрузчик NML — это ограничение игры,
никак нельзя сделать "просто положил exe и чит работает", BTD6 так не умеет.

1. Скачай NML: https://github.com/Natechillton/Mod-Loader/releases
   (страница может долго грузиться — подожди; нужен архив BTD6.zip)
2. Распакуй содержимое NML в папку с BloonsTD6.exe
3. Скопируй MoneyCheat.zip как есть в подпапку Mods\ внутри папки игры
   (распаковывать НЕ нужно — NML читает zip напрямую)
4. Запусти игру → F8 = +$10 000

Если ссылка на GitHub не открывается:
- зеркала NML есть на GameBanana: https://gamebanana.com/tools/7299
- или поиском "Nate's Mod Loader BTD6 github"
