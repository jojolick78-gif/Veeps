# BTD6 Money Cheat Mod (эксперимент)

Мод для **Bloons TD 6** через загрузчик модов **Nate's Mod Loader (NML)** / Nozomi.
Придумано как эксперимент: добавляет деньги (cash) в игре.

## Установка

1. Установи [Nate's Mod Loader](https://github.com/Natechillton/Mod-Loader) (NML) в папку игры BTD6.
2. Скопируй папку `Mods/MoneyCheat` в `BloonTDS6/Mods/` (туда же, где уже лежат другие моды NML).
   Структура должна быть такой:
   ```
   BTD6/
     Mods/
       MoneyCheat/
         Meta.json
         Behavior.json
   ```
3. Запусти игру. В главном меню открой меню N-Mods (шестерёнка / вкладка Mods) и включи **Money Cheat**.

## Использование

- **F8** — мгновенно добавить **+$10 000** текущей команде.
- В меню мода (Nozomi/NML):
  - поле **Add Cash Amount** — сумма (по умолчанию 10000);
  - кнопка **Add Cash** — добавить указанную сумму;
  - тумблер **Auto Cash per Second** — капля денег каждую секунду (выключен по умолчанию).

## Как это работает

Мод использует нативную функцию игры `AddCash` (через API Nozomi `natives.AddCash`),
которая легально вызывает внутриигровую логику начисления денег — поэтому деньги
корректно отображаются в HUD и синхронизируются с командой.

## Важно (для эксперимента)

- Используй только в **оффлайн-играх / своих кастомных лобби**. В мультиплеере
  читерские моды могут привести к бану и портят игру другим.
- Если игра обновилась и перестала видеть мод — обнови NML до последней версии.
- MD5 в `Meta.json` соответствует текущему `Behavior.json`. Если будешь править
  Behavior.json, пересчитай md5: `md5sum Behavior.json` и впиши в Meta.json.
